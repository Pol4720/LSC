# data/

The database. Everything here is **public-safe** because it is encrypted before
it is written.

| Path | What it holds |
|---|---|
| `submissions/<id>.json` | A client's answers, sealed with the advisor's public key (ECDH P-256 → HKDF → AES-256-GCM). |
| `crm/<id>.json` | The advisor's overlay for that client — stage, tags, notes, target lots. Sealed the same way. |
| `index.json` | A PII-free manifest (ids and timestamps only), regenerated by CI on every push. |
| `config/advisor-key.json` | The advisor's public key. |

Nothing in this folder can be read without the advisor's private key, which
never leaves their browser. Deleting a file here removes the record from every
future sync; git history keeps the ciphertext, which remains unreadable.
